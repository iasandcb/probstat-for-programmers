## 3.4 분산과 표준편차 
### 3.4.1 기댓값이 같아도...
```math
\begin{gather*}
X : \Omega _{ X } \to \left\lbrace 2 , \cdots , 16 \right\rbrace , Y : X : \Omega _{ Y } \to \left\lbrace 2 , \cdots , 16 \right\rbrace \\ 
E \left[ X \right] = E \left[ Y \right] = 9 \text{ but } f_X \ne f_Y
\end{gather*}
```
### 3.4.2 분산 = '기댓값에서 벗어난 상태'의 기댓값
```math
\begin{gather*}
\mu = E \left[ X \right] \\ 
E \left[ \left| X - \mu \right| \right] \times \\ 
V \left[ X \right] = E \left[ \left( X - \mu \right) ^{ 2 } \right] \\ 
\left( \mathbb{R} , d \right) \text{ where } d \left( x , y \right) = \left| x - y \right| , x , y \in \mathbb{R} \\ 
i . d \left( x , y \right) \ge 0 \text{ where } d \left( x , x \right) = 0 \\ 
ii . d \left( x , y \right) = d \left( y , x \right) \\ 
iii . d \left( x , y \right) + d \left( y , z \right) \ge d \left( x , z \right)
\end{gather*}
```
### 3.4.3 표준편차
```math
\begin{gather*}
\sigma = \sqrt{ V \left[ X \right] } \ge 0
\end{gather*}
```
### 3.4.4 정수 덧셈, 곱셈과 정규화
정수 = 상수
```math
\begin{gather*}
E \left[ a X + b \right] = a E \left[ X \right] + b \\ 
V \left[ Y \right] = V \left[ X + c \right] = V \left[ X \right] \implies \sigma \left[ Y \right] = \sigma \left[ X + c \right] = \sigma \left[ X \right] \\ 
V \left[ Z \right] = V \left[ c X \right] = c ^{ 2 } V \left[ X \right] \implies \sigma \left[ Z \right] = \sigma \left[ c X \right] = \left| c \right| \sigma \left[ X \right]
\end{gather*}
```

```math
Z = \frac{ X - \mu }{ \sigma } \\

\end{gather*}
```
### 3.4.5 독립이라면 덧셈의 분산은 분산의 덧셈
```math
\begin{gather*}
V \left[ X + Y \right] = V \left[ X \right] + V \left[ Y \right] \text{ where } X \text{ and } Y \text{are independent}
\end{gather*}
```
#### 예제 3.10
```math
\begin{gather*}
X \sim B \left( n , p \right) \\ 
V \left[ X \right] = V \left[ Z _{ 1 } + \cdots + Z _{ n } \right] = V \left[ Z _{ 1 } \right] + \cdots + V \left[ Z _{ n } \right] \\ 
V \left[ Z _{ i } \right] = E \left[ \left( X - p \right) ^{ 2 } \right] = \left( 0 - p \right) ^{ 2 } \left( 1 - p \right) + \left( 1 - p \right) ^{ 2 } p = p \left( 1 - p \right) \\ 
\therefore V \left[ X \right] = n p \left( 1 - p \right)
\end{gather*}
```
### 3.4.6 제곱 기댓값과 분산
```math
\begin{gather*}
V \left[ X \right] = E \left[ X ^{ 2 } \right] - E \left[ X \right] ^{ 2 }
\end{gather*}
```
편향과 편차
```math
\begin{gather*}
X, a(\text{이상}, \text{목표}) \\
E[(X-a)^2] : \text{제곱 오차} \\
E[(X-a)^2] = (E[X] - a)^2 (\text{편향(bias)}) + V[X] (\text{편차})
\end{gather*}
```
