# 3장 이산값의 확률분포
이산(discrete)
* 가산(countable): 자연수, 정수, 유리수 cf) 불가산(uncountable): 실수
* 위상수학에서는 전체공간에 대해 부군공간이 이산이다.
	* (실수, 실수의 표준(보통) 위상 = 개구간(기저)의 합집합): 실수를 위상공간화
		* (부분)공간이 이산이냐 아니냐
			* 정수: 이산. 정수의 모든 점이 격리(isolated), 즉 그 점만을 포집하는 개집합이 존재
			* 유리수: 이산 아님. 밀집(dense)

흔들리는 값 = 오차가 있는 값 
## 3.1 단순한 예
확률이란 무엇인가?
1. 확률 공간 도입 => 확률 측도 $P : F \to \left[ 0 , \infty \right]$ 사건이라는 집합의 크기가 확률
2. 확률 변수 도입 => 확률 분포(푸시포워드 측도) $X _{ \ast } \left( P \right) : \mathcal{ E } \to \left[ 0 , \infty \right]$ 사건에 대응하는 확률 변수값의 집합의 크기가 확률
3. 확률 (질량, 밀도) 함수 도입 => $f : E \to \left[ 0 , \infty \right)$ 결과에 대응하는 확률 변수값의 확률 함수 값이 확률
