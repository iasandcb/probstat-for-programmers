## 3.5.1 독립 동일 분포(i.i.d.)
independent and identically distributed
### 3.5.2 평균값의 기댓값, 평균값의 분산
```math
\begin{gather*}
Z = \frac{ X _{ 1 } + X _{ 2 } + \cdots + X _{ n } }{ n } \\ 
E \left[ Z \right] = \frac{ 1 }{ n } E \left[ X _{ 1 } + X _{ 2 } + \cdots + X _{ n } \right] = \frac{ 1 }{ n } \left( E \left[ X _{ 1 } \right] + \cdots + E \left[ X _{ n } \right] \right) = \frac{ 1 }{ n } \left( \mu + \cdots + \mu \right) = \mu \\ 
V \left[ Z \right] = \frac{ \sigma ^{ 2 } }{ n }
\end{gather*}
```
### 3.5.3 큰 수의 법칙
```math
\begin{gather*}
Z _{ n } = \frac{ X _{ 1 } + X _{ 2 } + \cdots + X _{ n } }{ n } \text{ where } E \left[ X _{ i } \right] = \mu \\ 
E \left[ Z _{ n } \right] = \mu = E \left[ X _{ i } \right] \\ 
V \left[ Z _{ n } \right] = \frac{ \sigma ^{ 2 } }{ n } \text{ where } \sigma = V \left[ X _{ i } \right] \\ 
\lim _{ n \to \infty } V \left[ Z _{ n } \right] = \lim _{ n \to \infty } \frac{ \sigma ^{ 2 } }{ n } = 0
\end{gather*}
```
