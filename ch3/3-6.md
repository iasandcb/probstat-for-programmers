## 3.6 조건부 기댓값과 최소제곱 예측
### 3.6.1 조건부 기댓값이란
```math
\begin{gather*}
E \left[ Y \mid X = a \right] = \sum _{ b } b P \left( Y = b \mid X = a \right)
\end{gather*}
```
### 3.6.2 최소제곱 예측
```math
\begin{gather*}
P \left( Y = b \mid X = a \right) \\ 
\hat{ Y } = g \left( X \right) \\ 
E \left[ \left( Y - \hat{ Y } \right) ^{ 2 } \right] \\ 
g \left( a \right) = E \left[ Y \mid X = a \right] \\ 
E \left[ \left( Y - \hat{ Y } \right) ^{ 2 } \right] = E \left[ \left( Y - g \left( X \right) \right) ^{ 2 } \right]
\end{gather*}
```
### 3.6.3 신의 관점에서
```math
\begin{gather*}
g \left( X \right) = E \left[ Y \mid X \right] \\ 
\implies E \left[ E \left[ Y \mid X \right] \right] = E \left[ g \left( X \right) \right] = E \left[ \hat{ Y } \right] = E \left[ Y \right]
\end{gather*}
```
### 3.6.4 조건부 분산
```math
\begin{gather*}
E \left[ Y \mid X = a \right] \coloneqq \mu \left( a \right) \\ 
V \left[ Y \mid X = a \right] = E \left[ \left( Y - \mu \left( a \right) \right) ^{ 2 } \mid X = a \right]
\end{gather*}
```
