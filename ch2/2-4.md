# 2.4 베이즈 공식
"프로그래머를 위한 확률과 통계" -> "프로그래머(저)가 강의하는 확률과 통계"
베이즈 정리(Bayes Theorem)
역문제
순문제: 원인 -> 결과 forward 기본 방향
역문제: 결과 -> 원인 backward 역방향 
원인 X를 직접 관측 측정 observe
메일 자동 필터링: X는 메일의 종류, Y는 메일 내용의 판정
```math
\begin{gather*}
P \left( X = 1 \mid Y = 0 \right) : \text{메일 내용을 광고 없음으로 판정했을 때 실제 메일의 종류가 광고일 확률}
\end{gather*}
```
## 2.4.1 문제 설정
* 원인(X): 사전 확률
* 원인(X)|결과(Y): 사후 확률(추가 정보)
```math
\begin{gather*}
A = \left( B , \mathcal{ B } \left( B \right) , P _{ B } \right) w h e r e B = \left\lbrace \text{함정있음} , \text{함정없음} \right\rbrace , P _{ B } \left( \text{함정있음} \right) = \frac{ 2 }{ 3 } , P _{ B } \left( \text{함정없음} \right) = \frac{ 1 }{ 3 } \\ 
C = \left( D , \mathcal{ B } \left( D \right) , P _{ D } \right) w h e r e D = \left\lbrace \text{낌새있음} , \text{낌새없음} \right\rbrace , P _{ B } \left( \text{낌새있음} \right) = \frac{ 7 }{ 12 } = P _{ B } \left( \text{낌새없음} \right) = \frac{ 5 }{ 12 } \\ 
X : \left( B , \mathcal{ B } \left( B \right) \right) \to \left( \left\lbrace 0 , 1 \right\rbrace , \mathcal{ B } \left( \left\lbrace 0 , 1 \right\rbrace \right) \right) w h e r e X \left( \text{함정없음} \right) = 0 , X \left( \text{함정있음} \right) = 1 \\ 
Y : \left( D , \mathcal{ B } \left( D \right) \right) \to \left( \left\lbrace 0 , 1 \right\rbrace , \mathcal{ B } \left( \left\lbrace 0 , 1 \right\rbrace \right) \right) w h e r e Y \left( \text{낌새없음} \right) = 0 , Y \left( \text{낌새있음} \right) = 1 \\ 
f : \left\lbrace 0 , 1 \right\rbrace \to \left[ 0 , 1 \right] w h e r e f \left( 0 \right) = P _{ B } \left( X ^{ {-1 } } \left( \left\lbrace 0 \right\rbrace \right) \right) = \frac{ 1 }{ 3 } , f \left( 1 \right) = P _{ B } \left( X ^{ {-1 } } \left( \left\lbrace 1 \right\rbrace \right) \right) = \frac{ 2 }{ 3 } \\ 
g : \left\lbrace 0 , 1 \right\rbrace \to \left[ 0 , 1 \right] w h e r e g \left( 0 \right) = P _{ D } \left( Y ^{ {-1 } } \left( \left\lbrace 0 \right\rbrace \right) \right) = \frac{ 5 }{ 12 } , g \left( 1 \right) = P _{ B } \left( Y ^{ {-1 } } \left( \left\lbrace 1 \right\rbrace \right) \right) = \frac{ 7 }{ 12 } \\ 
P \left( X = 1 \right) = f \left( 1 \right) = \frac{ 2 }{ 3 } \\ 
P \left( Y = 0 \mid X = 1 \right) = \frac{ 1 }{ 4 } \\ 
P \left( Y = 1 \mid X = 0 \right) = \frac{ 1 }{ 4 } \implies P \left( Y = 0 \mid X = 0 \right) = 1 - \frac{ 1 }{ 4 } = \frac{ 3 }{ 4 } \\ 
P \left( X = 1 \mid Y = 0 \right) = \frac{ P \left( X = 1 , Y = 0 \right) }{ P \left( Y = 0 \right) }
\end{gather*}
```

## 2.4.2 베이즈의 그림 그리는 노래
```math
\begin{gather*}
2. P \left( X = 1 \right) = \frac{ 2 }{ 3 } , P \left( X = 0 \right) = 1 - \frac{ 2 }{ 3 } = \frac{ 1 }{ 3 } \\ 
3. P \left( X = 1 , Y = 0 \right) = P \left( Y = 0 \mid X = 1 \right) P \left( X = 1 \right) = \frac{ 1 }{ 4 } \cdot \frac{ 2 }{ 3 } = \frac{ 1 }{ 6 } \\ 
4. P \left( X = 0 , Y = 0 \right) = P \left( Y = 0 \mid X = 0 \right) P \left( X = 0 \right) = \frac{ 3 }{ 4 } \cdot \frac{ 1 }{ 3 } = \frac{ 1 }{ 4 } \\ 
5. P \left( Y = 0 \right) = P \left( X = 1 , Y = 0 \right) + P \left( X = 0 , Y = 0 \right) = \frac{ 1 }{ 6 } + \frac{ 1 }{ 4 } = \frac{ 5 }{ 12 } \\ 
6. \frac{ \frac{ 1 }{ 6 } }{ \frac{ 5 }{ 12 } } = \frac{ 2 }{ 5 } = \frac{ P \left( X = 1 , Y = 0 \right) }{ P \left( Y = 0 \right) } = P \left( X = 1 \mid Y = 0 \right)
\end{gather*}
```
## 2.4.3 베이즈 공식
```math
\begin{gather*}
P \left( X = a \right) : \text{원인이 } a \text{인 확률(사전확률)} \\ 
P \left( Y = b \mid X = a \right) : \text{원인이 } a \text{일 때 결과가} b \text{인 조건부 확률(가능도)} \\ 
P \left( X = a \mid Y = b \right) : \text{결과가 } b \text{일 때 원인이} a \text{인 조건부 확률(사후확률)} \\ 
P \left( Y = b \right) : \text{결과가 } b \text{인 확률(증거)} \\ 
P \left( X = a \mid Y = b \right) = \frac{ P \left( X = a , Y = b \right) }{ P \left( Y = b \right) } \left( \text{조건부 확률 정의} \right) \\ 
P \left( X = a , Y = b \right) = P \left( Y = b \mid X = a \right) P \left( X = a \right) \text{를 대입하면} \\ 
P \left( X = a \mid Y = b \right) = \frac{ P \left( Y = b \mid X = a \right) P \left( X = a \right) }{ P \left( Y = b \right) } \\ 
P \left( X \mid Y \right) = \frac{ P \left( Y \mid X \right) P \left( X \right) }{ P \left( Y \right) } = \frac{ P \left( Y \mid X \right) }{ P \left( Y \right) } P \left( X \right)
\end{gather*}
```
