# 2.5 독립성
p. 88
조건부 확률: X -> Y 예측
베이즈 공식: X -> Y 영향 상태(X의 사전 분포) Y로부터 X를 맞히는 것
* 결합: P(X,Y)
* 조건부: P(Y|X)
* 베이즈(역조건부): P(X|Y) (cf. P(X))
## 2.5.1 사상의 독립성(정의)
사상 = 사건, 확률 변수의 특정한 경우(조건)
```math
\begin{gather*}
P \left( Y = 1 \mid X = 1 \right) = P \left( Y = 1 \mid X = 0 \right) = \frac{ 5 }{ 6 } \\ 
P \left( Y = 1 \mid X = 1 \right) = \frac{ P \left( Y = 1 , X = 1 \right) }{ P \left( X = 1 \right) } \\ 
P \left( Y = 1 \mid X = 0 \right) = \frac{ P \left( Y = 1 , X = 0 \right) }{ P \left( X = 0 \right) }
\end{gather*}
```
## 2.5.2 사상의 독립성(말 바꾸기)
```math
\begin{gather*}
1. Y = 1 \text{ and } X = 1 \text{ are independent} \\ 
2. P \left( Y = 1 \mid X = 1 \right) = P \left( Y = 1 \mid X \ne 1 \right) \\ 
3. P \left( Y = 1 \mid X = 1 \right) = P \left( Y = 1 \right) \\ 
4. P \left( Y = 1 , X = 1 \right) = P \left( Y = 1 \right) P \left( X = 1 \right)
\end{gather*}
```
Y와 X를 바꿔도 성립
```math
\begin{gather*}
2 ^{\prime} : P \left( X = 1 \mid Y = 1 \right) = P \left( X = 1 \mid Y \ne 1 \right) \\ 
3 ^{\prime} : P \left( X = 1 \mid Y = 1 \right) = P \left( X = 1 \right)
\end{gather*}
```
## 2.5.3 확률변수의 독립성
```math
\begin{gather*}
P \left( X , Y \right) = P \left( X \right) P \left( Y \right) \\ 
\forall a \in \text{ran} X , \forall b \in \text{ran} Y , P \left( X = a , Y = b \right) = P \left( X = a \right) P \left( Y = b \right)
\end{gather*}
```
## 2.5.4 세 개 이상의 독립성(요주의)
```math
\begin{gather*}
P \left( X , Y , Z \right) = P \left( X \mid Y , Z \right) P \left( Y \mid Z \right) P \left( Z \right) \\ 
P \left( X , Y \right) = P \left( X \mid Y \right) P \left( Y \right) \\ 
P \left( Y , Z \right) = P \left( Y \mid Z \right) P \left( Z \right) \\ 
P \left( Z , X \right) = P \left( Z \mid X \right) P \left( X \right)
\end{gather*}
```
조건부 확률을 안써서 표현하면
```math
\begin{gather*}
P \left( X , Y , Z \right) = P \left( X \right) P \left( Y \right) P \left( Z \right) \\ 
P \left( X , Y \right) = P \left( X \right) P \left( Y \right) \\ 
P \left( Y , Z \right) = P \left( Y \right) P \left( Z \right) \\ 
P \left( Z , X \right) = P \left( Z \right) P \left( X \right)
\end{gather*}
```
확률 변수의 독립
* 2개의 독립: 기본 정의
* 3개의 독립: 3개 중의 2개가 독립 + 3개가 같이 독립
* 4개의 독립: 4개 중의 3개가 독립 + 4개가 같이 독립
