## 2.3 조건부 확률
### 2.3.1 조건부 확률이란
```math
\begin{gather*}
P \left( A \mid B \right) = \frac{ P \left( A \cap B \right) }{ P \left( B \right) } \\ 
예 ) \quad P \left( A \cap B \right) = \frac{ 1 }{ 3 } , P \left( B \right) = \frac{ 1 }{ 2 } \implies P \left( A \mid B \right) = \frac{ \frac{ 1 }{ 3 } }{ \frac{ 1 }{ 2 } } = \frac{ 2 }{ 3 }
\end{gather*}
```
### 2.3.2 결합분포, 주변분포, 조건부분포의 관계
```math
\begin{gather*}
P \left( B \right) P \left( A \mid B \right) = P \left( A \cap B \right)
\end{gather*}
```
