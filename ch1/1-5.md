## 1.5 확률 분포
```math
\begin{gather*}
\left( \Omega , \mathcal{ F } , P \right) : \text{확률공간} \\ 
P : \mathcal{ F } \to \mathbb{R} \\ 
i . \text{cod} P \subseteq \left[ 0 , 1 \right] \text{ or } \forall x \in F \text{ s.t. } P \left( x \right) \in \left[ 0 , 1 \right] \iff 0 \le P \left( x \right) \le 1 \\ 
ii . P \left( \Omega \right) = 1 \\ 
iii . P \left( \cup _{ i = 1 } ^{ \infty } A _{ i } \right) = \sum \nolimits _{ i = 1 } ^{ \infty } P \left( A _{ i } \right) \text{ where } A _{ i } \in F \\ 
\left( E , \mathcal{ E } \right) : \text{가측공간} \\ 
X : \left( \Omega , \mathcal{ F } \right) \to \left( E , \mathcal{ E } \right) \text{ or } X : \Omega \to \mathbb{R} \\ 
X : \text{가측함수} \implies X : \text{확률변수}
\end{gather*}
```
확률분포(PD): 쪽매김 측도(pushforward measure)
```math
\begin{gather*}
X _{ \ast } \left( P \right) : \mathcal{ E } \to \left[ 0 , + \infty \right] \\ 
\forall B \in \mathcal{ E } , X _{ \ast } \left( P \right) \left( B \right) = P \left( X ^{ {-1 } } \left( B \right) \right) \\ 
\therefore \left( E , \mathcal{ E } , X _{ \ast } \left( P \right) \right) : \text{측도공간}
\end{gather*}
```
## 1.6 실전용 축약법
확률함수(PF)
### 확률질량함수(PMF)
이산(discrete) 확률 변수
* 유한
* 셀수 있는 무한: 자연수, 정수
	* 유리수: 퀴즈
```math
\begin{gather*}
f : E \to \left[ 0 , 1 \right] \\ 
\sum _{ x \in E } f \left( x \right) = 1 \\ 
\mathbf{ P } \left( X = x \right) = f \left( x \right)
\end{gather*}
```
---
동전 한번 던지기 시행의 경우
```math
\begin{gather*}
\Omega = \left\lbrace \text{H} , \text{T} \right\rbrace , \mathcal{ F } = 2 ^{ \Omega } = \left\lbrace \varnothing , \left\lbrace \text{H} \right\rbrace , \left\lbrace \text{T} \right\rbrace , \left\lbrace \text{H} , \text{T} \right\rbrace \right\rbrace \\ 
P \left( \left\lbrace \text{H} , \text{T} \right\rbrace \right) = 1 , P \left( \varnothing \right) = 0 , P \left( \left\lbrace \text{H} \right\rbrace \right) = 1 {/} 2 = P \left( \left\lbrace \text{T} \right\rbrace \right) \\ 
E = \left\lbrace 0 , 1 \right\rbrace , \mathcal{ E } = 2 ^{ E } = \left\lbrace \varnothing , \left\lbrace 0 \right\rbrace , \left\lbrace 1 \right\rbrace , \left\lbrace 0 , 1 \right\rbrace \right\rbrace \\ 
X : \left( \Omega , \mathcal{ F } \right) \to \left( E , \mathcal{ E } \right) \text{ where } X \left( \text{T} \right) = 0 , X \left( \text{H} \right) = 1 \\ 
f : E \to \left[ 0 , 1 \right] \text{ where } f \left( 0 \right) = P \left( \left\lbrace \text{T} \right\rbrace \right) = \frac{ 1 }{ 2 } , f \left( 1 \right) = \frac{ 1 }{ 2 } = P \left( \left\lbrace \text{H} \right\rbrace \right) \\ 
\mathbf{ P } \left( X = 0 \right) = f \left( 0 \right) = \frac{ 1 }{ 2 } \\ 
\mathbf{ P } \left( X = 1 \right) = f \left( 1 \right) = \frac{ 1 }{ 2 }
\end{gather*}
```
### 확률밀도함수(PDF)
연속 확률 변수
* 실수

```math
\begin{gather*}
f : E \to \left[ 0 , \infty \right) \\ 
\int _{ E } f = 1 \\ 
\mathbf{ P } \left( a \le X \le b \right) = \int _{ a } ^{ b } f
\end{gather*}
```
