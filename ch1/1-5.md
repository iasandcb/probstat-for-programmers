# 1.5 확률 분포
```math
\begin{gather*}
\left( \Omega , \mathcal{ F } , P \right) : \text{확률공간} \\ 
\left( E , \mathcal{ E } \right) : \text{가측공간} \\ 
X : \text{확률변수}
\end{gather*}
```
확률분포(PD): 쪽매김 측도(pushforward measure)
```math
\begin{gather*}
X _{ \ast } \left( P \right) : \mathcal{ E } \to \left[ 0 , + \infty \right] \\ 
\forall B \in \mathcal{ E } , X _{ \ast } \left( P \right) \left( B \right) = P \left( X ^{ {-1 } } \left( B \right) \right)
\end{gather*}
```
# 1.6 실전용 축약법
확률함수(PF)
## 확률질량함수(PMF)
이산(discrete) 확률 변수
* 유한
* 셀수 있는 무한: 자연수, 정수
	* 유리수: 퀴즈
```math
\begin{gather*}
f : E \to \left[ 0 , 1 \right] \\ 
\sum _{ x \in E } f \left( x \right) = 1 \\ 
P \left( X = x \right) = f \left( x \right)
\end{gather*}
```
## 확률밀도함수(PDF)
연속 확률 변수
* 실수

```math
\begin{gather*}
f : E \to \left[ 0 , \infty \right) \\ 
\int _{ E } f = 1 \\ 
P \left( a \le X \le b \right) = \int _{ a } ^{ b } f
\end{gather*}
```
