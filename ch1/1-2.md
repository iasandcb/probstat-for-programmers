## 1.2.2 정답과 흔한 착각
유지 전략시 승리 확률은 단순히 3가지 문 중의 차 문 하나를 고를 확률이므로
```math
\frac{ 1 }{ 3 }
```
변경 전략은 유지 전략의 반대(여사건)이므로
```math
1 - \frac{ 1 }{ 3 } = \frac{ 2 }{ 3 }
```
