### 4.3.1 확률밀도함수
* 한국: 라지 엑스 스몰 엑스
* 미국: 소문자(lowercase, little) 엑스 대문자(uppercase, capital, big) 엑스 
* 일본: 대문자 엑스, 소문자 엑스
```math
\begin{gather*}
F _{ X } \left( a \right) = P \left( X \le a \right) \\ 
f _{ X } \left( x \right) = F _{ X } ^{\prime} \left( x \right) = \frac{ \text{d} F _{ X } \left( x \right) }{ {\text{d}x} } \\ 
\frac{ a }{ b } \left( a \text{ over(나누기) } b \right)
\end{gather*}
```
* 이탤릭(기울림 italic): 변수 이름(식별자)
* 로만(세움 roman): 기호, 상수
```math
\begin{gather*}
\text{e} : \text{자연로그의 밑} \\ 
P \left( a \le X \le b \right) = \int _{ a } ^{ b } f _{ X } \left( x \right) {\text{d}x}
\end{gather*}
```
고등학교 때 배운 적분: 리만(다르부) 적분
미분 -> 적분
적분 -> 미분
미적분학의 기본정리 
구분구적법(아르키메데스) => 리만 합 => 극한 => 리만 적분 (정적분, 적분이 값) => 미분(도함수)
```math
\begin{gather*}
i . \int _{ a } ^{ x } f \left( t \right) {\text{d}t} = F \left( x \right) \iff f \left( x \right) = \frac{ \text{d} F \left( x \right) }{ {\text{d}x} } \iff F \left( x \right) : \text{부정적분(원시함수)} \\ 
ii . \int _{ a } ^{ b } f \left( x \right) {\text{d}x} = F \left( b \right) - F \left( a \right) \text{ where } F \left( x \right) \text{ is an antiderivative}
\end{gather*}
```
확률 변수
```math
\begin{gather*}
X : \Omega \to \mathbb{R} \\ 
P \left( - \infty < X < \infty \right) = 1 = P \left( \mathbb{R} \right) = \int _{ - \infty } ^{ \infty } f _{ X } \left( x \right) {\text{d}x} = 1
\end{gather*}
```
유계(bounded, 위아래로 한계가 있다) 연속함수는 리만적분 가능하며 르베그 적분도 동일하다. 
불연속함수의 경우 불연속점(무한개라면?)의 집합의 르베그 측도 값이 0이어야 리만적분이 가능하다.
* 가산 무한 집합의 르베그 측도는 0 (거의 모든 점에서 연속)
* 불가산인 경우 아니다.
유리수 지시 함수(디리클레 함수)
```math
\begin{gather*}
f \left( x \right) = \left\lbrace \begin{array}{ll} 1 & x \in \mathbb{Q} \\ 0 & x \notin \mathbb{Q} \end{array} \right. \\ 
D = \left\lbrace x \in \left[ 0 , 1 \right] \mid f \left( x \right) \text{is discontinuous} \right\rbrace = \left[ 0 , 1 \right] \left( \text{모든 점에서 불연속} \right) \\ 
\lambda \left( D \right) = 1 \ne 0 \implies \int _{ 0 } ^{ 1 } f \left( x \right) {\text{d}x} \text{ 리만적분불가} \\ 
\int _{ \left[ 0 , 1 \right] } f \text{d} \lambda = 1 \cdot \lambda \left( \mathbb{Q} \cap \left[ 0 , 1 \right] \right) + 0 \cdot \lambda \left( \mathbb{Q} ^{ c } \cap \left[ 0 , 1 \right] \right) \\ 
= 1 \cdot 0 + 0 \cdot 1 = 0 \left( \text{르베그적분가능} \right)
\end{gather*}
```
[0,1] 안의 무리수 지시 함수
```math
\begin{gather*}
f \left( x \right) = \left\lbrace \begin{array}{ll} 1 & x \in \mathbb{Q} ^{ c } \cap \left[ 0 , 1 \right] \\ 0 & x \notin \mathbb{Q} ^{ c } \cap \left[ 0 , 1 \right] \end{array} \right. \\ 
D = \left\lbrace x \in \left[ 0 , 1 \right] \mid f \left( x \right) \text{is discontinuous} \right\rbrace = \left[ 0 , 1 \right] \left( \text{모든 점에서 불연속} \right) \\ 
\lambda \left( D \right) = 1 \ne 0 \implies \int _{ 0 } ^{ 1 } f \left( x \right) {\text{d}x} \text{ 리만적분불가} \\ 
\int _{ \mathbb{R} } f \text{d} \lambda = 1 \cdot \lambda \left( \mathbb{Q} ^{ c } \cap \left[ 0 , 1 \right] \right) + 0 \cdot \lambda \left( \mathbb{Q} \cup \left( - \infty , 0 \right) \cup \left( 1 , \infty \right) \right] ) \\ 
= 1 \cdot 1 + 0 = 1 \left( \text{확률밀도함수가능} \right)
\end{gather*}
```
참고로 이 f는 균등 분포의 PDF를 g라 하면 거의 어디서나 같다( f = g a.e.(almost everywhere)).
#### 예제 4.5
```math
\begin{gather*}
f _{ X } \left( x \right) = \left\lbrace \begin{array}{ll} \text{e} ^{ {-x } } & x \ge 0 \\ 0 & x < 0 \end{array} \right. \\ 
\int _{ - \infty } ^{ \infty } f _{ X } \left( x \right) {\text{d}x} = \int _{ - \infty } ^{ 0 } 0 {\text{d}x} + \int _{ 0 } ^{ \infty } \text{e} ^{ {-x } } {\text{d}x} \\ 
= \lim _{ a \to \infty } \int _{ 0 } ^{ a } \text{e} ^{ {-x } } {\text{d}x} = \lim _{ a \to \infty } \left[ - \text{e} ^{ {-x } } \right] _{ 0 } ^{ a } = \lim _{ a \to \infty } - \text{e} ^{ {-a } } + \text{e} ^{ {-0 } } \\ 
= \lim _{ a \to \infty } - \frac{ 1 }{ \text{e} ^{ a } } + 1 = 0 + 1 = 1
\end{gather*}
```

### 4.3.3 확률밀도함수의 변수 변환
치환적분
#### 예제 4.9
```math
\begin{gather*}
X : \Omega \to \mathbb{R} \\ 
f _{ X } \left( x \right) = \left\lbrace \begin{array}{ll} \frac{ 1 }{ 3 } & 0 \le x \le 3 \\ 0 & x < 0 \text{ or } x > 3 \end{array} \right. \\ 
Y = \left( X + 1 \right) ^{ 2 } \\ 
y = \left( x + 1 \right) ^{ 2 } \implies {\text{d}y} = 2 \left( x + 1 \right) {\text{d}x} \implies {\text{d}x} = \frac{ 1 }{ 2 \left( x + 1 \right) } {\text{d}y} \\ 
\sqrt{ y } = x + 1 \implies x = \sqrt{ y } - 1 \\ 
P \left( a \le X \le b \right) = \int _{ a } ^{ b } f _{ X } \left( x \right) {\text{d}x} \\ 
= \int _{ \left( a + 1 \right) ^{ 2 } } ^{ \left( b + 1 \right) ^{ 2 } } f _{ X } \left( \sqrt{ y } - 1 \right) \frac{ 1 }{ 2 \left( \sqrt{ y } - 1 + 1 \right) } {\text{d}y} \\ 
= \int _{ \left( a + 1 \right) ^{ 2 } } ^{ \left( b + 1 \right) ^{ 2 } } f _{ X } \left( \sqrt{ y } - 1 \right) \frac{ 1 }{ 2 \sqrt{ y } } {\text{d}y} \\ 
= \int _{ \left( a + 1 \right) ^{ 2 } } ^{ \left( b + 1 \right) ^{ 2 } } f _{ Y } \left( y \right) {\text{d}y} \\ 
\therefore f _{ Y } \left( y \right) = \frac{ f _{ X } \left( \sqrt{ y } - 1 \right) }{ 2 \sqrt{ y } }
\end{gather*}
```
