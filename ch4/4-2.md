## 4.2 확률 0
```math
\begin{gather*}
\left( \Omega , F , P \right) \\ 
X : \left( \Omega , F \right) \to \left( \mathbb{R} , \mathcal{ B } \left( \mathbb{R} \right) \right) \\ 
f_X : \mathbb{R} \to \left[ 0 , \infty \right) \\ 
f_X = \frac{ \text{d} P }{ \text{d} \lambda } \left( \text{라돈 니코님 도함수} \right) \\ 
\int _{ A } \text{d} P = \int _{ a } ^{ b } f_X \text{d} \lambda \text{ where } A \in F \text{ and } \left[ a , b \right] \in \mathcal{ B } \left( \mathbb{R} \right) \\ 
A = \left\lbrace a \right\rbrace \implies \int _{ A } \text{d} P = \int _{ a } ^{ a } f_X \text{d} \lambda = 0
\end{gather*}
```
