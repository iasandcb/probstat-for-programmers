## 4.6 정규분포와 중심극한정리
### 4.6.1 표준정규분포
```math
\begin{gather*}
Z \sim N \left( 0 , 1 \right) \\ 
f _{ Z } \left( z \right) = \frac{ 1 }{ \sqrt{ 2 \pi } } \exp \left( - \frac{ z ^{ 2 } }{ 2 } \right) = \frac{ 1 }{ \sqrt{ 2 \pi } } \text{e} ^{ - \frac{ z ^{ 2 } }{ 2 } } \\ 
f _{ Z } = \frac{ \text{d} P }{ \text{d} \lambda } \implies P \left( A \right) = \int _{ A } f \text{d} \lambda \text{ where } A \in F
\end{gather*}
```
### 4.6.2 일반정규분포
```math
\begin{gather*}
X \sim N \left( \mu , \sigma ^{ 2 } \right) \\ 
Z = \frac{ X - \mu }{ \sigma } \left( \text{정규화} \right)
\end{gather*}
```
### 4.6.3 중심극한정리
참고: 큰 수의 정리
#### p. 218
```math
\begin{gather*}
W _{ n } = \frac{ X _{ 1 } + \cdots + X _{ n } }{ \sqrt{ n } \sigma } \\ 
\lim _{ n \to \infty } P \left( W _{ n } \le a \right) = P \left( Z \le a \right)
\end{gather*}
```
