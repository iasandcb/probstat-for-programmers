## 4.5 기댓값과 분산, 표준편차
### 4.5.1 기댓값
```math
\begin{gather*}
E \left[ X \right] = \sum _{ x } x f _{ X } \left( x \right) \left( \text{PMF} \right) \\ 
E \left[ X \right] = \int _{ - \infty } ^{ \infty } x f _{ X } \left( x \right) {\text{d}x} \left( \text{PDF} \right)
\end{gather*}
```
#### 예제 4.15
```math
\begin{gather*}
X : \left( \Omega , F \right) \to \left( \mathbb{R} , \mathcal{ B } \left( \mathbb{R} \right) \right) \\ 
f _{ X } : \mathbb{R} \to \left[ 0 , 1 \right] \\ 
f _{ X } \left( x \right) = \left\lbrace \begin{array}{cc} 2 x & 0 \le x \le 1 \\ 0 & \text{기타} \end{array} \right\rbrace \\ 
\int _{ - \infty } ^{ \infty } f _{ X } \left( x \right) {\text{d}x} = \int _{ 0 } ^{ 1 } 2 x {\text{d}x} = \left[ 2 \frac{ x ^{ 2 } }{ 2 } \right] _{ 0 } ^{ 1 } = 1 \\ 
E \left[ X \right] = \int _{ - \infty } ^{ \infty } x f _{ X } \left( x \right) {\text{d}x} = \int _{ 0 } ^{ 1 } x \cdot 2 x {\text{d}x} = \int _{ 0 } ^{ 1 } 2 x ^{ 2 } {\text{d}x} = \left[ 2 \cdot \frac{ x ^{ 3 } }{ 3 } \right] _{ 0 } ^{ 1 } \\ 
= \frac{ 2 }{ 3 }
\end{gather*}
```
### 4.5.2 분산, 표준편차
```math
\begin{gather*}
\mu = E \left[ X \right] \\ 
V \left[ X \right] = E \left[ \left( X - \mu \right) ^{ 2 } \right] = E \left[ X ^{ 2 } \right] - E \left[ X \right] ^{ 2 }
\end{gather*}
```
#### 예제 4.19
```math
\begin{gather*}
\mu = \frac{ 2 }{ 3 } \\ 
V \left[ X \right] = E \left[ X ^{ 2 } \right] - \left( \frac{ 2 }{ 3 } \right) ^{ 2 } \\ 
E \left[ X ^{ 2 } \right] = \int _{ - \infty } ^{ \infty } x ^{ 2 } f _{ X } \left( x \right) {\text{d}x} = \int _{ 0 } ^{ 1 } x ^{ 2 } 2 x {\text{d}x} = \int _{ 0 } ^{ 1 } 2 x ^{ 3 } {\text{d}x} = \left[ 2 \frac{ x ^{ 4 } }{ 4 } \right] _{ 0 } ^{ 1 } \\ 
= \frac{ 1 }{ 2 } \\ 
\therefore V \left[ X \right] = \frac{ 1 }{ 2 } - \frac{ 4 }{ 9 } = \frac{ 9 }{ 18 } - \frac{ 8 }{ 18 } = \frac{ 1 }{ 18 }
\end{gather*}
```
