```math
\begin{gather*}
f \left( x \right) = F ^{\prime} \left( x \right) = \frac{ \text{d} F \left( x \right) }{ {\text{d}x} }
\end{gather*}
```
스몰 에프 엑스는 라지 에프 프라임 엑스 는 디 라지 에프 엑스 디 엑스
```math
\begin{gather*}
\int _{ a } ^{ b } f \left( x \right) {\text{d}x} = F \left( b \right) - F \left( a \right)
\end{gather*}
```
