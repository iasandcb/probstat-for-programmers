### 4.4.1 결합분포
```math
\begin{gather*}
W \coloneqq \left( X , Y \right) \\ 
\text{pdf} \left( W \right) = f _{ X , Y } \left( x , y \right) \\ 
P \left( a \le X \le b \text{ and } c \le Y \le d \right) \\ 
= \int _{ c } ^{ d  } \left( \int _{ a } ^{ b } f _{ X , Y } \left( x , y \right) {\text{d}x} \right) {\text{d}y} \\ 
= \int _{ a } ^{ b } \left( \int _{ c } ^{ d  } f _{ X , Y } \left( x , y \right) {\text{d}y} \right) {\text{d}x} \\ 
= \int \int _{ R } f _{ X , Y } \left( x , y \right) \text{d} A
\end{gather*}
```

f _{ X , Y } \left( x , y \right) = \left\lbrace \begin{array}{ll} \exp \left( - x - y \right) & x \ge 0 \text{ or } y \ge 0 \\ 0 & \text{otherwise} \end{array} \right. \\ 
P \left( 0 \le X \le 1 \text{ and } 0 \le Y \le 1 \right) = \int _{ 0 } ^{ 1 } \int _{ 0 } ^{ 1 } \exp \left( - x - y \right) {\text{d}x} {\text{d}y} = \left( 1 \right) \\ 
\int \text{e} ^{ - x } {\text{d}x} = - \text{e} ^{ - x } + C \\ 
\int \text{e} ^{ - x - y } {\text{d}x} = \int \text{e} ^{ - x } \text{e} ^{ - y } {\text{d}x} = \text{e} ^{ {-y } } \int \text{e} ^{ {-x } } {\text{d}x} = - \text{e} ^{ - y } \text{e} ^{ {-x } } + C \\ 
\left( 1 \right) = \int _{ 0 } ^{ 1 } \left[ - \text{e} ^{ - y } \text{e} ^{ {-x } } \right] _{ 0 } ^{ 1 } {\text{d}y} = \int _{ 0 } ^{ 1 } - \text{e} ^{ {-y } } \left( \text{e} ^{ {-1 } } - \text{e} ^{ 0 } \right) {\text{d}y}

### 4.4.2 서둘러 진도를 나가고 싶다면
```math
\begin{gather*}
i . P \left( X = a \right) = \sum _{ y } P \left( X = a , Y = y \right) = f _{ X } \left( a \right) = \sum _{ y } f _{ X , Y } \left( a , y \right) = \int _{ - \infty } ^{ \infty } f _{ X , Y } \left( a , y \right) {\text{d}y} \\ 
ii . P \left( Y = b \mid X = a \right) = \frac{ P \left( X = a , Y = b \right) }{ P \left( X = a \right) } = f _{ Y \mid X } \left( b \mid a \right) = \frac{ f _{ X , Y } \left( a , b \right) }{ f _{ X } \left( a \right) } \\ 
P \left( X = a , Y = b \right) = P \left( Y = b \mid X = a \right) P \left( X = a \right) = f _{ X , Y } \left( a , b \right) = f _{ Y \mid X } \left( b \mid a \right) f _{ X } \left( a \right) \\ 
iii . P \left( X = a \mid Y = b \right) = \frac{ P \left( Y = b \mid X = a \right) P \left( X = a \right) }{ P \left( Y = b \right) } \\ 
= \frac{ P \left( Y = b \mid X = a \right) P \left( X = a \right) }{ \sum _{ x } P \left( X = x , Y = b \right) } = \frac{ P \left( Y = b \mid X = a \right) P \left( X = a \right) }{ \sum _{ x } P \left( Y = b \mid X = x \right) P \left( X = x \right) } \\ 
= f _{ X \mid Y } \left( a \mid b \right) = \frac{ f _{ Y \mid X } \left( b \mid a \right) f _{ X } \left( a \right) }{ \sum _{ x } f _{ Y \mid X } \left( b \mid x \right) f _{ X } \left( x \right) } = \frac{ f _{ Y \mid X } \left( b \mid a \right) f _{ X } \left( a \right) }{ \int _{ - \infty } ^{ \infty } f _{ Y \mid X } \left( b \mid x \right) f _{ X } \left( x \right) {\text{d}x} } \\ 
i v . P \left( X = a , Y = b \right) = P \left( X = a \right) P \left( Y = b \right) = f _{ X , Y } \left( a , b \right) = f _{ X } \left( a \right) f _{ Y } \left( b \right)
\end{gather*}
```
